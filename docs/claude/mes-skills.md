# Mes skills (Claude Code)

Quatre familles, repérées par le préfixe du nom :
- `travail-` : notre façon de travailler ensemble (ensemble, decortiquer, coach) ;
- `conception-` : bonnes pratiques de conception (specifier, coherence) ;
- `projet-` : bonnes pratiques de gestion de projet (prioriser, decisions, sessions) ;
- `safe-` : repères SAFe (pratiques).

Rien n'est propre à un projet : les chemins, la branche et les documents du projet sont dans son CLAUDE.md.

## Installer dans un projet
Copier le dossier `.claude/skills/` à la racine du dépôt du projet, commit + push, et citer les skills dans son
CLAUDE.md. Une session Claude Code charge les skills du dépôt (de la branche) à son démarrage.
