# Glossaire (les mots qui portent une règle ; définir avant de concevoir)

- **Note** : ce qu'on écrit en réunion (Information, Blocage, Décision à prendre / prise, Demande d'action, Risque,
  Dépendance, Proposition). Information = type par défaut, fermée d'office.
- **Concrétiser** : décider ce que devient une note : Type (Rien · Créer un élément · Action rapide · Demande de
  budget) → À qui → Suivi.
- **Point de suivi** : une note concrétisée et suivie jusqu'à validation (En cours → Fait → Validé ; ou À reprendre,
  Abandonné, Plus suivi).
- **Action rapide** : une action à faire sans créer d'élément, toujours suivie (13/10).
- **Affecter** : donner la responsabilité à moi ou à une personne de mon équipe.
- **Transmettre** : passer à quelqu'un hors du cas normal : responsable absent (remplaçant), autre équipe, niveau du
  dessus. Englobe l'ancienne « escalade » (vers le haut). Toujours suivi.
- **Maillon** : chaque niveau (équipe, train, portfolio, entreprise) par lequel passe une transmission ou une demande ;
  chacun décide ou transmet plus haut, jamais automatiquement.
- **Hors réunion** : décision prise dans le Chat ; elle est confirmée ensuite en réunion.
- **Plus suivi** : le point n'est plus une alerte, l'élément créé continue sa vie (≠ Abandonné : plus besoin).
- **Enveloppe** : budget annuel d'un niveau ; Engagé = budgets prévus des projets lancés + demandes accordées.
