# Décisions

- Chaque décision validée est notée **avec sa date** dans le fichier de relais du projet (section « Décisions du
  JJ/MM ») : ce qui est décidé, en une ou deux lignes, et pourquoi si ce n'est pas évident.
- Trois états : **décidé**, **à décider** (avec ma recommandation), **écarté** (avec la raison).
- Si une demande contredit une décision passée : le rappeler (« le 08/10 on avait décidé … ; on change ? ») et
  noter la nouvelle décision qui remplace l'ancienne.
- Les questions encore ouvertes en fin de session vont dans le fichier de relais pour la session suivante.
